# Выпуски новостей

Сюда кладутся готовые выпуски. Всё, что здесь лежит со `status: "published"`,
попадает на сайт в раздел `/news/`.

## Порядок работы

1. **Собрать кандидатов**

   ```
   node _tools/news/collect.mjs --days 7
   ```

   Сборщик читает ленты, оставляет то, что задевает одновременно ИИ и
   деловую сторону, склеивает повторы и кладёт черновик в
   `_tools/news/drafts/ГГГГ-ММ-ДД.json`.

2. **Разобрать черновик.** Лишние новости удалить — пять-семь на выпуск
   рабочий размер. У каждой оставшейся заполнить `take`: что это значит для
   бизнеса. Два-четыре предложения. Дописать `title` выпуска и `intro`.

3. **Опубликовать.** Поставить `"status": "published"` и перенести файл
   из `drafts/` в `issues/`.

4. **Собрать сайт** — `bash _tools/build-all.sh`.

## Чего сборка не простит

**Пустой `take`** — сборка падает. Новость без разбора это пересказ чужого
заголовка: её публикуют сотни площадок в тот же час, и ради неё раздел не
нужен. Ценность здесь только в вашем мнении.

**Выпусков нет вообще** — раздел не создаётся. Пустая лента новостей вредит:
посетитель видит «последнее обновление — никогда» и делает вывод обо всём
сайте.

## Когда выйдет первый выпуск

Добавить «Новости» в меню — в `_tools/shared/site.json`, поле `nav`. Сейчас
пункта нет намеренно: он вёл бы в никуда.

И про ритм. Раздел работает, только пока выходит регулярно. Заброшенный
через месяц вредит сильнее, чем помогал бы: свежесть — единственное, чем
новость выигрывает у остального содержимого сайта.
